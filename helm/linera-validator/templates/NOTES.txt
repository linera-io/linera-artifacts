{{- if and (not .Values.validator.existingSecret) (not .Values.validator.serverConfigData) }}

WARNING: validator.serverConfigData is empty and validator.existingSecret
is not set. The pods will fail to start because they have no signing key.

Obtain your per-validator server config (PRIVATE signing key) and the
network's public genesis.json from the Linera network operators, then
create a Kubernetes Secret with those two files:

  kubectl --namespace {{ .Release.Namespace }} create secret generic validator-config \
    --from-file=serverConfig=./server.json \
    --from-file=genesisConfig=./genesis.json

Upgrade with `--set validator.existingSecret=validator-config`.
{{- end }}

Check pod status:
  kubectl --namespace {{ .Release.Namespace }} get pods -l \
    app.kubernetes.io/instance={{ .Release.Name }}

Tail logs:
  kubectl --namespace {{ .Release.Namespace }} logs -f \
    statefulset/{{ include "linera-validator.componentPrefix" . }}shards
  kubectl --namespace {{ .Release.Namespace }} logs -f \
    statefulset/{{ include "linera-validator.componentPrefix" . }}proxy
